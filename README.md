## Start a lesson

1. Extract the ZIP into a local folder and double-click **Open SiMetropolis Edu**. The Mac download requires macOS 12 or later. If you already use the Windows `start-product.cmd` shortcut from a checkout, it also opens Edu.
2. Keep internet access on for first-use setup. The launcher shows download progress. If the transfer stops, reconnect and select **Retry**.
3. In the teacher browser tab, choose English or 繁體中文 and click **Start class**. The 45-minute timer starts immediately.
4. On the classroom network, select **Project join information**. Groups on the same Wi-Fi or Ethernet network can scan the QR code, follow the link, or enter the short code on their own device.

If Edu detects a network problem, the teacher tab shows **Open network settings** and keeps retrying. Join information returns when the computer reconnects, and the original countdown continues.

Keep the launcher running throughout the lesson. If you close the teacher tab, double-click **Open SiMetropolis Edu** again from the same folder to reopen the class with the same code, timer, and group work.

See the [Long Valley classroom guide](classroom/README.md) for teaching and setup details.

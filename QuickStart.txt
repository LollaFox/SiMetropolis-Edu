1. On Mac, follow the Terminal setup and launch commands in README.md. On Windows, double-click Open SiMetropolis Edu.cmd in the project folder.
2. In the teacher tab, select A railway across Long Valley, choose the starting language and click Start Lesson. On the classroom network, select Launch the QR code page for your groups.
3. Keep the Terminal or launcher window open. To reopen the teacher tab, run the Mac launch command in a second Terminal window from the same folder, or double-click the Windows shortcut again.
